## [1.2.0] - 2026-08-01

### Added

- Chrome Extension built with Manifest V3.
- Privacy-focused tracker blocking using Declarative Net Request.
- Analytics Dashboard for monitoring blocked trackers.
- Settings page with whitelist and blacklist management.
- Export and reset statistics functionality.
- Badge counter displaying blocked trackers.
- Daily tracker statistics reset.
- Activity logging.
- Protected websites counter.
- Responsive user interface.
- Modern popup dashboard.
- GitHub documentation.

### Improved

- Optimized storage management.
- Improved statistics handling.
- Cleaner project structure.
- Enhanced user interface.
- Better performance when tracking blocked requests.

### Fixed

- Analytics page statistics synchronization.
- Site counter updates.
- Daily reset issues.
- Manifest configuration improvements.
- Storage initialization.
- Badge update consistency.
