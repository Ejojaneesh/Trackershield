# Contributing to TrackerShield

Thank you for your interest in contributing to TrackerShield!

We welcome contributions that improve the extension, documentation, and user experience.

---

## Getting Started

1. Fork the repository.
2. Clone your fork locally.

```bash
git clone https://github.com/Ejojaneesh/TrackerShield.git
```

3. Create a new branch.

```bash
git checkout -b feature/your-feature
```

4. Make your changes.

5. Commit your work.

```bash
git commit -m "Describe your changes"
```

6. Push your branch.

```bash
git push origin feature/your-feature
```

7. Open a Pull Request.

---

## Contribution Guidelines

- Write clean and readable code.
- Follow the existing project structure.
- Test new features before submitting.
- Keep commits focused and descriptive.
- Update documentation when necessary.

---

## Reporting Issues

Please include:

- Operating System
- Chrome Version
- Extension Version
- Steps to reproduce
- Expected behavior
- Actual behavior

---

## Feature Requests

Feature requests are always welcome.

Please describe:

- The problem
- Your proposed solution
- Any alternatives considered

---

## Code Style

- Use meaningful variable names.
- Comment complex logic.
- Keep functions modular.
- Follow JavaScript best practices.
