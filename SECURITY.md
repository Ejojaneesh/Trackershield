# Security Policy

## Supported Versions

The following versions of TrackerShield currently receive security updates.

| Version | Supported |
|----------|-----------|
| 1.2.x | ✅ Yes |
| 1.1.x | ❌ No |
| 1.0.x | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability in TrackerShield, please report it responsibly.

Please include:

- A clear description of the issue.
- Steps to reproduce the vulnerability.
- Screenshots or logs (if applicable).
- The version of TrackerShield.
- Your operating system and browser version.

---

## Response Process

Every reported issue will be:

1. Reviewed.
2. Verified.
3. Fixed if confirmed.
4. Released in a future update.

Responsible disclosure is appreciated.

---

## Security Features

TrackerShield includes the following privacy and security features:

- Tracker blocking using Chrome Declarative Net Request API.
- Local-only statistics storage.
- No collection of personal browsing history.
- No external servers.
- No user tracking.
- Manifest V3 architecture.
- Permission-based access.
